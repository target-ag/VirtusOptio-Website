# Security and maintenance

This is a static website hosted on Cloudflare Pages. It has no customer database,
sign-in system, payment processing, or server-side application code.

## Publishing checks

The production build runs:

```sh
pip install -r requirements.txt
mkdocs build --strict
python scripts/check_security.py site
```

`docs/_headers` restricts scripts and styles to this site, disables inline event
handlers and embedded frames, and prevents other sites from framing the pages.
The small first-paint theme initializer is allowed by its exact SHA-256 hash,
generated by `hooks/assets.py`. Do not add `unsafe-inline` or `unsafe-eval` to
work around a failed build. Put new scripts in local files and review their use.

The same hook bundles shared CSS under a content-fingerprinted filename. Fonts
are self-hosted; their license and sources are in `docs/assets/fonts/`.

The HTML compatibility check catches common policy conflicts. It is not a
complete vulnerability scanner or a substitute for reviewing new templates.
Markdown and templates must come from trusted authors. Draft posts are excluded
from the production build, but any draft committed to this public repository
is publicly readable source; never commit confidential material or credentials.

## Updates and account protection

Review dependency advisories and update the pinned requirements regularly.
After updates, run a strict build, the compatibility check, `pip check`, and a
dependency advisory scan such as `pip-audit -r requirements.txt`. Check the home,
blog, article, and 404 pages in both themes before publishing.

Keep the configured Python runtime on a supported security patch. Update both
`.python-version` and the Cloudflare Pages `PYTHON_VERSION` setting together.
The local Python interpreter is maintained separately from Python packages.

Protect GitHub, Cloudflare, and the domain registrar with multifactor
authentication and recovery codes. Limit access to people who publish or manage
the site. DNSSEC, if enabled, must be coordinated between Cloudflare and the
registrar so that the registrar's DS record matches Cloudflare's current key.

HSTS currently applies only to the requested hostname. Do not add
`includeSubDomains` or request preload until every subdomain supports HTTPS.
