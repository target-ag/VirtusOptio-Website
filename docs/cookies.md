## Our current setup

Virtus Optio does not currently use optional advertising or analytics cookies, tracking pixels, embedded social-media widgets or a third-party chat widget. There is no advertising or analytics consent to enable on this website.

The site uses one browser preference to remember a light or dark theme when you choose it. This is **local storage**, rather than a cookie: it remains in your browser and is not automatically attached to website requests.

## Saved theme preference

| Item | Details |
| --- | --- |
| Name | `virtus-optio-theme` |
| Type | First-party local storage |
| Values | `light` or `dark` |
| Purpose | Remember the appearance you select |
| When saved | When you use the theme switch |
| Duration | No automatic expiry; remains until cleared by you or your browser |
| Removal | Use [Cookie Settings](cookie-settings.md) or clear this site's browser data |

This functional preference contains no name or contact details and is not used to track you across websites. The initial visit reads any existing preference but does not create one simply because you opened the page.

## Hosting and security

Cloudflare serves and protects this website. Its security features may use necessary cookies if a challenge or another relevant protection is activated. These are not advertising choices; the cookies that apply depend on the security feature in use. See [Cloudflare's cookie information](https://developers.cloudflare.com/fundamentals/reference/policies-compliances/cloudflare-cookies/).

Cloudflare also enables browser network-error reporting for delivery diagnostics. This is not the theme preference or an advertising cookie. See our [Privacy Policy](privacy.md) for technical request processing and provider information.

## External services

The email, WhatsApp and LinkedIn links take you to your chosen application or another service. Those services may use their own cookies and storage after you open them. We do not embed their widgets or control their settings here.

## Manage your choices

Open [Cookie Settings](cookie-settings.md) to view and clear the saved theme preference. Your browser also lets you block or remove cookies and site data. Removing the theme preference returns this site to light mode; you can still use the site and change the theme again.

If optional tracking features are introduced later, this information and the controls will be updated, and consent will be requested before using features that require it.
